# 🎥 Screen Recorder

A lightweight, modern, and user-friendly screen recorder. It allows you to record your entire screen with simple controls for **Start**, **Pause/Resume**, and **Stop**, automatically saving videos in `.mp4` format.

---

## 🚀 Features

- 🔴 **Real-Time Recording**: Smooth screen capture with optimized frame rate (FPS).
- ⏸️ **Pause & Resume**: Pause your recording at any moment without splitting the file.
- 📁 **Automatic Saving**: Videos are saved directly into the `recordings/` folder with a timestamp.
- 🎨 **Simple Interface**: Clean and minimalist GUI.
